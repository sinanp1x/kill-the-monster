# kill-the-monster

A p5.js + Matter.js physics game where a superhero fights a monster using ropes and boxes. The player controls a hero (superhero1/2.png) and uses physics-based ropes (Rope.js) to attack a monster (monster.png). Boxes (Box.js), ground (Ground.js), and the monster itself (Monster.js) are Matter.js bodies.

## Tech Stack

- **p5.js** — canvas-based creative coding library
- **p5.play.js** — sprite and collision support for p5.js
- **Matter.js** — 2D physics engine

## How to Run

Open `index.html` in a browser — no build step required. All libraries are vendored in the repo.
