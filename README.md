# kill-the-monster

A p5.js + Matter.js physics game where a superhero fights a monster using ropes and boxes.



## Tech Stack

- **p5.js** — canvas-based creative coding library
- **p5.play.js** — sprite and collision support for p5.js
- **Matter.js** — 2D physics engine (where applicable)

## How to Run

Open  in a browser — no build step required. All libraries are vendored in the repo.
